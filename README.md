# 🗄️ WorkByte Database

Database system for **WorkByte**, supporting core application data such as users, jobs, and proposals.

---

## 📌 Overview

This repository manages the database layer of WorkByte, including:

* Schema definitions
* Enum types
* Relationships between entities
* Data consistency with backend services

---

## 🏗️ Tech Stack

* **Database**: PostgreSQL
* **Containerization**: Docker

---

## 🐳 Development

All development is done inside the Docker container environment.
